# ViLink Calculadora

Herramienta de campo para armar pantallas LED (gabinetes 0,5 × 1 m · 128 × 256 px).

## Uso rápido

Abrí `index.html` en el navegador. Funciona offline.

## Funciones

- Pantallas múltiples (principal + secundarias)
- Gabinetes interior / exterior
- Data (serpentina + hot-backup) y Power (reparto pareja, máx. 15–16)
- Truss automático 24×24 / 30×30 + piezas 3 m · 2 m · 1 m
- Bumpers 1 m (2 gabinetes) · 2 lingas por bumper · Aparejos 1 t
- Configuración (peso, potencia, límites)
- Stock por ítem y por sección de truss (24×24, 30×30, 40×40, 30×40)
- Eventos activos con reserva de stock
- Exportar / importar JSON · Imprimir resumen
